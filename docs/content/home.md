# Consoland

Welcome to Consoland, This website is an experiment in making a website framework with the help of Claude Code. Like a really bare bones way to assemble a website out of markdown documents. As well as a repository for software that I think is worth sharing. There is a real focus on command-line application for windows, but Other programs may end up here as well.

## What's here

- **Games** — small hand-built games.
- **Utilities** — command-line tools.
- **Blog Archive** — Archive of my very short medium blog. 
- **Canary** — The stuff used to make this site.
