# Tesselate

A vibe coded falling block game in the soviet tradition. All in your command Line.

## Features

1. Playable from the command line, while your waiting for a task to complete or an agent to finish
2. Updated mechanics: Lives, On Fire bar, Preview Swap
3. Great Midi Soundtrack (Game defaults to no music)
4. Local Highscore List saved in user app-data
5. Pointless save game feature you will never use
6. Command line options you will never use
