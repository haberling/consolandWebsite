Consoland

This site is a repository for software I think is worth sharing, focusing on command-line tools for Windows. There's llote, a command-line note-taker with local semantic search; Tesselate, a command-line falling block game; Canary, the web framework this site runs on; ScanMan, a barcode scanner clipboard utility; and a blog about building them.

If you get any use or joy out of things on this site, consider buying me a coffee.
