# Consoland

This site is a repository for software I think is worth sharing, focusing on command line tools for Windows. There's [llote](utilities/llote), a command-line note-taker with local semantic search; [Tesselate](games/Tesselate), a command line falling block game; [Canary](canary), the web framework this site runs on; [ScanMan](utilities/ScanMan), a barcode scanner clipboard utility; and a [blog](blog) about building them.

If you get any use or joy out of things on this site, consider [buying me a coffee](https://buymeacoffee.com/mhaberlingk).
